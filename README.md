# R for Biology workshop

Materials for the R for Biology workshop (MSc Translational Neuroscience, Imperial College London): single-cell RNA-seq with Seurat and cell-type enrichment with EWCE.

**[Download the latest materials](https://github.com/neurogenomics/r-for-biology-workshop/releases/latest)**. No login needed.

1. **R-for-Biology-setup.zip**: download about a week before the workshop. Unzip it and open `introduction-and-setup.pdf`, which explains what to install and how to check it works.
2. **R-for-Biology-worksheets.zip**: the worksheets for both days. Unzip it somewhere you can find again.

Questions: ask a tutor in the session, or email any of the tutors beforehand.
